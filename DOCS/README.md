🎓 University Admissions Bot
A chatbot application designed to help students get quick and clear information about university admissions, including eligibility criteria, application procedures, required documents, and important deadlines.

📖 Description
The University Admissions Bot acts as a virtual admission assistant.
It compresses lengthy admission guidelines into simple conversational responses, making it easier for students to understand and complete the admission process efficiently.

✨ Key Features
📚 Course and program details
✅ Eligibility criteria
📝 Step-by-step application process
📄 Required documents information
📅 Admission deadlines
❓ Frequently asked questions (FAQs)
🛠️ Technologies Used
Chatbot / NLP framework
Python / JavaScript (based on implementation)
JSON / CSV for data storage
GitHub for version control
⚙️ How It Works
User asks an admission-related question
Bot identifies the intent
Relevant admission information is retrieved
A clear response is displayed to the user
